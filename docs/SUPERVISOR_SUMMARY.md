# Global Content Intelligence Platform — Plain-Language Summary

*One page, no technical background needed. July 2026.*

## What we have today

An interactive world atlas covering **all 195 countries**, showing how people in each country consume media: which platforms they use (including radio and TV, not just social media), which news sources they trust, how free the press is, and how connected the population is. Every number is traceable to a reputable source — the World Bank, Reporters Without Borders, Freedom House, the Reuters Institute at Oxford, and the Afrobarometer research network. The data refreshes itself automatically every week without anyone lifting a finger.

## What we are building next (12 weeks)

We are evolving the atlas into an **AI communications analyst**. Instead of browsing tables, a communications officer will simply ask a question in plain English:

> *"Where should we publish climate change content targeting young people in East Africa?"*

…and receive a clear recommendation — which countries, which platforms, which content formats, when — **with every claim backed by a named, clickable source and an honest confidence rating**. When the data can't support an answer, the system says so instead of guessing. Credibility is the entire point.

## What's being added

1. **Live topic trends.** Starting now, the system tracks global attention to ~170 UN-relevant topics (climate, health, refugees, misinformation, AI, gender equality…) across 22 languages, updated every day, using two free, reputable public data streams: Wikipedia reading patterns (what people *look up*) and the GDELT global news monitor (what media *publish*).
2. **Country intelligence.** Daily calculations of what's rising, falling, and trending in each country.
3. **The AI analyst.** A chat interface, built on the same technology as Claude, that answers questions using only our verified data — with citations.
4. **New pages.** "Trending now" on every country profile, a Topic Explorer, and a guided Recommendation Builder.

## What it costs

Everything — the data, the hosting, the daily automation — is **free**. The only cost in the entire project is the AI service subscription for the chat feature: approximately **US$5–25 per month** at pilot usage. There is nothing else to buy and no servers to maintain.

## What it will NOT do

- It will not collect any personal data — all information is country-level and from public, licensed sources.
- It will not guess. Where data is missing (some small countries have limited survey coverage), it says so explicitly.
- It will not require technical staff to keep running. The automation is self-sustaining, and full handover documentation is part of the delivery.
